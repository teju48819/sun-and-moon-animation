# ☀️ Sun & Moon Animation

A simple web animation that creates a visual day and night scene using HTML and CSS.

## ✨ Features

- Animated sun and moon
- Day and night visual effect
- Pure HTML and CSS
- Lightweight and easy to run
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 How to Run

1. Clone this repository.
2. Open `index.html` in your browser.
3. Enjoy the animation.
